🛠️ THE TOOLS — Instalador de Ferramentas para Termux

THE TOOLS é uma ferramenta desenvolvida em Python para Termux, criada para facilitar a instalação e organização de diversos utilitários essenciais em um único programa.

Com uma interface colorida e interativa, o instalador apresenta um catálogo com 50 ferramentas, organizadas por categorias como Desenvolvimento, Editores e Terminal, Rede e Conectividade, Utilitários de Sistema, Dados e Texto, Bancos de Dados, Multimídia e Segurança.

🚀 Principais recursos

- 📦 Instalação automática de ferramentas através do "pkg"
- 🗂️ Ferramentas organizadas por categorias
- 🔧 Instalação de todas as ferramentas de uma vez
- 🎯 Instalação apenas das categorias escolhidas
- 🔄 Atualização automática dos repositórios do Termux
- 📊 Barra de progresso durante a instalação
- 📝 Sistema de log para registrar instalações concluídas e falhas
- 🎨 Interface colorida com banner personalizado
- 💻 Detecção do ambiente Termux
- 🐍 Exibição da versão do Python utilizada
- ⚡ Interface simples e fácil de utilizar

📚 Categorias disponíveis

Desenvolvimento
Git, Python, Node.js, Go, Rust, Clang, Java, PHP e Make.

Editores & Terminal
Vim, Neovim, Nano, Tmux, Zsh, Fish e Micro.

Rede & Conectividade
Curl, Wget, OpenSSH, Nmap, Net-tools, Rsync, Proot e Termux:API.

Utilitários de Sistema
Htop, Neofetch, Tree, Zip, Unzip, Tar, Which, Ncdu, Man e Termux-tools.

Dados & Texto

Bancos de Dados

Multimídia
FFmpeg, ImageMagick e YouTube-dl.

Segurança
GnuPG e OpenSSL.

🎯 Objetivo

O objetivo do THE TOOLS é economizar tempo e facilitar a preparação de um ambiente Termux para programação, desenvolvimento, administração de sistemas, redes, automação, bancos de dados e outras tarefas técnicas.

Em vez de executar vários comandos "pkg install" manualmente, o usuário pode utilizar uma única interface para selecionar e instalar as ferramentas desejadas.

«⚠️ Observação: as ferramentas instaladas pertencem aos respectivos projetos e desenvolvedores. O THE TOOLS funciona principalmente como um instalador e organizador dos pacotes disponíveis no ambiente Termux.»
